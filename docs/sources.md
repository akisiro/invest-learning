# 来源与版权

## 项目来源

建站灵感来自 [Financial_freedom](https://github.com/codeman008/Financial_freedom)。本模板重新编写了页面和学习任务，整理了书目信息、纪录片片名、频道及工具入口，没有搬运原 README 的介绍、推荐语、视频或书籍文件。

## 内容规则

- 只发布自己的笔记，或有明确适用许可的内容，并记录许可与来源。
- 不上传或链接来源不明的书籍 PDF、扫描件、整本译文。
- 原作年代较早不等于某个译本、排版或扫描件可以自由传播。
- 资源链接优先指向作者、出版社、图书馆或官方平台。
- 署名本身不能替代授权。

本站尚未选定原创内容的开放许可；第三方内容的权利归其权利人所有。发布者可在明确权利范围后添加适用许可证。
