# 数据与工具

原项目还包含美股网站和 Web3 工具。下面先收录可用于学习的数据与资料入口，按用途重新整理。链接资料核对日期：2026-10-16；各网站功能、价格和可访问地区以其当前说明为准。

## 美股研究

| 工具 | 学习用途 | 核对资料 |
| --- | --- | --- |
| [FINVIZ](https://finviz.com/) | 练习用条件筛选股票，记录筛选口径 | [官方筛选器说明](https://elite.finviz.com/help/screener) |
| [Seeking Alpha](https://seekingalpha.com/) | 比较不同作者对同一公司的论点，回查原始信息 | [官方介绍](https://about.seekingalpha.com/) |

## Web3 数据观察

| 工具 | 学习用途 | 核对资料 |
| --- | --- | --- |
| [DefiLlama](https://defillama.com/) | 观察 DeFi 数据，核对指标定义 | [官方数据接口文档](https://api-docs.defillama.com/) |

## 原项目中其他资源的整理状态

| 分类 | 本站处理 |
| --- | --- |
| 美股论坛与网站导航 | 先收录以上两个研究入口，其他旧链接待逐项核实 |
| 行情、链上分析、代币解锁 | 保留分类，后续核对域名与数据口径后补充 |
| 交易所、钱包、跨链、DEX、质押和 NFT 交易 | 原目录含注册邀请及交易入口，本版先不迁移；不影响阅读学习资源 |
