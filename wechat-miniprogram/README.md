# 投资学习手册 · 微信小程序本地版

无需云开发、无需服务器、无第三方依赖。资源目录随代码打包；收藏、状态、进度、定位和笔记只写入当前设备的微信本地存储，不上传 GitHub 或网站。

## 导入运行

1. 下载仓库：GitHub Code → Download ZIP，解压。
2. 打开微信开发者工具，选择「导入项目」。目录选择仓库中的 **wechat-miniprogram**，不是仓库根目录。
3. AppID 填入 `wxb4a30c81e27c961a`，使用管理员微信登录。后端服务如需选择，选「不使用云服务」。
4. 导入后点击「编译」，应看到资源库、我的学习、备份三个标签。
5. 点击「预览」，用管理员微信扫码真机验证。暂不点击上传或提审；正式上线仍需完成平台相关审核要求。

## 使用

资源库可按种类与关键词筛选。点开资源后，收藏、选择学习状态、拖动进度、填写章节和笔记，最后点击「保存记录」。进度到 100% 会标记完成；选择已完成也会设置 100%。其他状态和进度以你的操作为准。

外部链接通过「复制资源链接」交由浏览器打开，小程序不使用 web-view，也不内嵌外部视频。没有链接的纪录片标为待核实。频道沿用原目录入口，尚未逐一核实。

## 备份

「备份」页点击「生成备份」→「复制备份文字」，自行保存完整文字。换设备后粘贴并导入；导入前会确认，同一资源由备份覆盖，其他资源保留。备份只包含学习记录，不含资源目录。

本地存储不是加密保险箱，也没有账号隔离。清理微信数据、移除小程序或换手机可能丢失记录。模拟器与真机数据各自独立。不要把私人备份提交到公开仓库。

每项笔记最多 20000 字，定位说明最多 120 字。应用限制总记录文字规模以减小本地存储失败概率；写入失败会提示，不显示成功，也不把现有记录清空。

## 验证范围

自动检查覆盖 JS 语法、JSON 配置、页面文件完整性、目录条数、本地存储保存/恢复、损坏备份和写入失败。微信开发者工具编译、真机排版及剪贴板行为需要在你的工具和手机上验证。

## 数据来源

资源目录来自本仓库 docs 中已整理的书目、纪录片、频道和工具；资源链接不是对第三方内容或商家的担保。说明与主题为本项目重新编写，不复制原项目推荐语或书籍全文。

## 开发检查

安装 Node.js 的环境可运行 `node tests/storage.test.js`。本项目不使用任何 API 密钥或 AppSecret。
